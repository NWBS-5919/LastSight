1. 한 문장 문제 정의

공장의 기존 화재경보설비는 화재 발생과 대피 명령을 전달하지만, 경보 이후 CCTV 관측 범위 내 작업자가 실제로 출구를 통과했는지와 출구 통과가 확인되지 않은 사람이 마지막으로 어느 구역에서 관측되었는지를 자동으로 정리하기 어렵다.

2. 제안 배경

2-1. 기존 화재 대응의 구조

화재감지기 작동 → 경종·시각경보·비상방송 → 작업자 대피 → 집결지에서 수동 인원 확인 → 미확인자가 있으면 관리자·동료에게 질문 → CCTV를 되돌려 마지막 위치 확인 → 소방대에 예상 인원과 위치를 구두로 전달

현재의 공백은 “화재가 발생했다는 사실을 알리는 것”과 “실제로 누가 대피했는지 확인하는 것” 사이에 있다.

2-2. 기존 방식의 한계

현재 방식현장 한계
출근명부·출입기록으로 재실자 확인이미 퇴근하거나 일시 외출한 사람이 포함될 수 있음
사원 명부 중심 집계협력업체·방문자·파견·일용직 근로자가 누락될 수 있음
집결지에서 이름을 부르며 확인소음, 혼란, 부상, 언어 차이로 확인이 지연될 수 있음
동료의 기억에 의존긴급상황에서 마지막 위치 기억이 부정확할 수 있음
관리자가 CCTV를 직접 재생여러 카메라의 과거 영상을 짧은 시간 안에 검토하기 어려움
카메라에서 사람이 사라지면 판단 불가대피, 가림, 사각지대 이동을 구분하기 어려움
이름만 구조대에 전달현장 구조대가 해당 작업자의 모습을 모를 수 있음
현재 CCTV 영상만 확인연기·정전·카메라 장애 이후에는 작업자를 확인하기 어려움

3. 서비스 정의

3-1. 정식 주제명

Vision AI 기반 공장 화재 대피 이행 확인 및 미확인 작업자 마지막 관측 정보 제공 시스템

3-2. 서비스 소개

LastSight AI는 기존 CCTV 영상을 활용해 화재경보 전후 작업자의 이동을 추적하고, 출구 가상선 통과 여부에 따라 상태를 분류하는 화재 대응 보조 서비스이다.

상태정의
대피 확인작업자가 출구선을 내부에서 외부로 통과한 장면이 확인됨
내부 관측화재경보 이후에도 공장 내부 구역에서 계속 관측됨
출구 미확인출구 통과 없이 가림·사각지대·저시야 등으로 추적이 중단됨

3-3. 핵심 가치

화재 발생을 다시 탐지하는 것이 아니라, 화재경보 이후 관리자가 여러 CCTV를 직접 되돌려보는 시간을 줄이고 구조에 필요한 정보를 빠르게 정리한다.

5. 주제의 경쟁력

5-1. 문제 재정의의 차별성

LastSight AI는 화재·연기 탐지, PPE 감지 같은 단일 기능에 머무르지 않고, 사건 흐름을 다음과 같이 연결한다.

사람 탐지 → 임시 ID 추적 → 출구 통과 판정 → 대피 상태 분류 → 마지막 관측 프레임 선택 → 구조 브리핑 카드 생성

5-2. 공모전 평가와의 연결

데이터 기획정상 상황뿐 아니라 가림, 동일 복장, 집단 대피, 추적 중단, 카메라 장애를 포함

6. 서비스 범위와 안전한 표현

6-1. 시스템이 판단하는 것

  • CCTV 화면에 보이는 사람
  • 영상 내 작업자의 임시 추적 ID
  • 작업자가 위치한 카메라·구역
  • 출구 가상선 통과 여부
  • 경보 이후 내부 관측 여부
  • 출구 통과 없는 추적 중단
  • 마지막 관측 위치·시각
  • 제한된 보호구·복장 정보

6-2. 시스템이 판단하지 않는 것

  • 공장 전체의 정확한 총인원
  • CCTV가 없는 공간의 재실 여부
  • 출구 미확인 작업자가 실제로 현재 내부에 남아 있는지
  • 얼굴 기반 신원·국적·인종·성별·나이·체형
  • 구조대원의 진입 경로
  • AI 단독 전원 대피 완료 선언
핵심 표현 원칙: “잔류자를 확정한다”가 아니라 “CCTV 관측 범위 내 출구 통과가 확인되지 않은 작업자를 분류한다”고 설명한다.

7. 전체 서비스 작동 흐름

1단계. 평상시 모니터링

  • CCTV 영상에서 작업자를 탐지한다.
  • 작업자마다 영상 내 임시 추적 ID를 부여한다.
  • 각 카메라를 공장 평면도의 구역과 연결한다.
  • 출구 위치에는 가상선을 설정한다.
  • 이름·사번·얼굴 정보와 연결하지 않는다.

2단계. 화재신호 입력

입력 항목예시
화재구역B구역 포장실
경보 시작시각14:03:00
사용 불가 통로B구역 동측 통로
사용 가능 출구1번·2번 출구
안내 언어한국어·영어·베트남어

3단계. 다국어·시각 대피 안내

사업장에서 사전에 등록한 주요 언어를 동시에 출력하고, 얼굴을 보고 국적이나 사용할 언어를 추정하지 않는다.

4단계. 대피 이동 추적

  • 출구선을 안쪽에서 바깥쪽으로 통과했는가
  • 경보 후 내부 구역에 계속 머무르는가
  • 출구 통과 없이 화면에서 사라졌는가
  • 출구에 접근했지만 통과하지 않고 되돌아갔는가
  • 대피 후 외부에서 내부로 재진입했는가

5단계. 작업자 상태 분류

상태판정 기준화면 표시
대피 확인출구선을 내부→외부로 완전히 통과초록색
내부 관측경보 후에도 내부 구역에서 계속 탐지빨간색
출구 미확인출구 통과 없이 추적이 중단주황색
재진입 경고대피 확인 후 외부→내부 재통과빨간색 경고
카메라 확인 불가영상 중단 또는 심한 저시야회색 경고

6단계. 마지막 관측 정보 저장

  • 마지막 탐지 프레임
  • 마지막 관측 카메라·구역·시각
  • 마지막 이동 방향
  • 출구 통과 기록 유무
  • 추적 중단 원인 추정값

7단계. 참조 프레임 선택

마지막 관측 이미지와 가장 선명한 참조 이미지를 함께 제공한다.

8단계. 제한된 인상착의 구조화

항목출력 예시
안전모노란색 안전모
안전조끼주황색 반사조끼
상의남색 작업복
마지막 위치C구역 창고 입구
마지막 시각14:03:18
출구 통과미확인

9단계. 구조 브리핑 카드 생성

노란색 안전모와 주황색 안전조끼, 회색 상의를 착용한 작업자입니다. 마지막으로 14시 03분 18초에 C구역 창고 입구에서 서쪽 창고 방향으로 이동하는 모습이 관측되었습니다. 출구 통과 기록은 확인되지 않았습니다.

10단계. 관리자 검토 및 전달

  • AI가 생성한 구조카드는 관리자가 확인한다.
  • 관리자는 상태와 속성 정보를 수정할 수 있다.
  • 공모전 MVP에서는 소방기관 시스템으로 자동 전송하지 않는다.
  • 현장 안전관리자가 소방대 지휘관에게 화면을 제시한다.

15. 데모 시나리오

  1. 작업자 4명이 공장 내부에서 작업한다.
  2. 관리자가 B구역 화재 버튼을 누른다.
  3. 전광판과 음성으로 사용 가능한 출구를 다국어 안내한다.
  4. P01과 P02가 출구 1로 대피한다.
  5. P03이 출구 2로 대피한다.
  6. P04는 C구역 방향으로 이동한다.
  7. 디지털 연기 또는 설비 가림으로 P04의 추적이 중단된다.
  8. 시스템은 P01~P03의 출구 통과를 확인한다.
  9. P04는 출구 통과 기록 없이 추적이 중단되어 출구 미확인으로 표시된다.
  10. P04의 마지막 관측 구역·시각·방향을 저장한다.
  11. 가장 선명한 참조 이미지를 선택해 구조카드를 만든다.
  12. 관리자가 구조카드를 검토한 뒤 지휘관용 화면으로 전환한다.

19. 서비스 한계

  • CCTV가 설치되지 않은 구역은 분석할 수 없다.
  • 화장실·탈의실처럼 촬영이 제한된 공간의 재실자는 확인할 수 없다.
  • 심한 연기·정전·카메라 파손 이후 현재 위치는 알 수 없다.
  • 동일한 복장을 입은 여러 사람이 교차하면 추적 ID가 바뀔 수 있다.
  • 마지막 관측 위치는 현재 위치가 아니다.
  • AI 결과만으로 소방대원의 진입 여부나 수색 경로를 결정해서는 안 된다.
  • 실제 화재영상이 아닌 연출·합성 데이터를 사용하므로 현장 성능은 별도 검증이 필요하다.

23. 최종 발표 구성

문제

화재경보는 울리지만 모든 작업자가 실제로 출구를 통과했는지는 자동으로 확인되지 않습니다.

해결책

LastSight AI는 CCTV 영상에서 작업자를 탐지·추적하고, 출구 가상선 통과를 기준으로 대피 이행을 확인합니다.

안전 원칙

출구 통과 없이 추적이 끊긴 작업자는 대피 완료가 아니라 출구 미확인으로 분류합니다.

차별점

화재를 발견하는 AI가 아니라, 화재 이후 어디에서 누구를 우선 확인해야 하는지 알려주는 AI입니다.

24. 심사위원 예상 질문과 답변

Q1. 카메라에서 사람이 사라지면 대피한 것으로 잘못 판단하지 않나요?

출구선을 내부에서 외부로 완전히 통과한 장면이 확인된 경우만 대피 확인으로 처리한다. 출구 통과 없이 화면에서 사라지면 출구 미확인으로 분류한다.

Q2. 잔류 인원 수를 정확하게 알 수 있나요?

공장 전체 잔류 인원을 확정하는 시스템은 아니다. CCTV 관측 범위 내에서 출구 통과가 확인된 사람과 확인되지 않은 사람을 구분하는 보조 시스템이다.

Q3. 동일한 작업복을 입은 작업자를 어떻게 구분하나요?

복장만으로 동일인을 확정하지 않는다. 객체 추적의 임시 ID를 사용하며, IDF1과 ID Switch를 평가한다.

Q4. 왜 얼굴인식을 사용하지 않나요?

신원 자동식별이 반드시 필요하지 않고 개인정보 부담이 크기 때문이다. 사건 내 임시 ID와 참조 이미지, 보호구·복장 정보만 제공한다.

Q5. Superb AI 플랫폼은 어디에 사용하나요?

데이터 관리, 영상·이미지 라벨링, 품질 검수, 모델 학습 또는 학습용 데이터 구축, 오류 데이터 선별과 반복 개선에 활용한다.
